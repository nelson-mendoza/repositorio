Estructura del Sistema

Arquitectura modular para escalabilidad y mantenimiento:

  • Backend: Lógica central en app.py y validaciones en rules.py.
  • Frontend: 7 plantillas Jinja2 para UX fluida.
  • Assets: JavaScript puro y CSS industrial en static/.

Instalación Paso a Paso

Configuración completa del entorno Linux:

Paso 1: Dependencias Python

pip install -r requirements.txt

Paso 2: Motor PDF (wkhtmltopdf)

sudo dpkg -i wkhtmltopdf_0.12.6-2build2_amd64.deb

Paso 3: Dependencias Críticas

sudo apt install -f

⚠️ Este paso resuelve librerías de fuentes requeridas para renderizado PDF en Linux.

Seguridad y Protección de Datos

Arquitectura de seguridad construida desde el núcleo:

  • Hash SHA-256 con Salt: Cada usuario genera un salt aleatorio único antes del hashing.
  • Protección contra ataques: Resistente a rainbow tables y credential reuse.
  • Validaciones backend: Mitigación de SQL Injection y XSS en todos los endpoints.
  • Sesiones con expiración: Cierre automático por inactividad para equipos compartidos.
SeguridadSlide 6

Generación de PDFs: pdfkit vs FPDF

Decisión arquitectónica crítica para el proyecto:

  • FPDF: Ligero pero limitado a coordenadas cartesianas (X, Y).
  • pdfkit + wkhtmltopdf: Renderizado HTML5/CSS3 completo.
  • WYSIWYG: El PDF generado es idéntico a lo que ve el usuario.
Ventajas de pdfkit:
✓ Diseño responsive
✓ Tipografías web
✓ Imágenes integradas
✓ CSS print media
✗ Requiere binarios externos

Campos del Contrato

El formulario captura la esencia legal de un acuerdo en 4 pilares:

Identidad

Nombre del prestador (trabajador) y del cliente contratante.

El Servicio

Descripción detallada de la tarea y ubicación exacta del trabajo.

Acuerdo Económico

Monto total y cláusula de penalización por incumplimiento.

Personalización

Subida de logotipo para un acabado profesional en el PDF.

Retos Técnicos Superados

Desafíos encontrados durante el desarrollo:

  • UTF-8 y caracteres especiales: Solucionado con encoding correcto en pdfkit.
  • ñ y vocales acentuadas: Configuración de fuentes en wkhtmltopdf.
  • Gestión de archivos temporales: Limpieza automática de logotipos subidos.
  • Renderizado Linux inconsistente: Resuelto con sudo apt install -f.
